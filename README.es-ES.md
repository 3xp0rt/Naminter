# Naminter

[![PyPI Version](https://img.shields.io/pypi/v/naminter)](https://pypi.org/project/naminter/)
[![Python Version](https://img.shields.io/badge/python-3.11%2B-blue)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Downloads](https://img.shields.io/pypi/dm/naminter)](https://pypi.org/project/naminter/)
[![GitHub Stars](https://img.shields.io/github/stars/3xp0rt/naminter?style=social)](https://github.com/3xp0rt/naminter)

Naminter es un paquete de Python y una herramienta de interfaz de línea de comandos (CLI) para la enumeración asíncrona de nombres de usuario OSINT utilizando el conjunto de datos de WhatsMyName. Aprovechando la exhaustiva lista de [WhatsMyName](https://github.com/WebBreacher/WhatsMyName), Naminter enumera nombres de usuario en cientos de sitios web. Con funciones avanzadas como la suplantación de navegador (browser impersonation), enumeración asíncrona y filtrado personalizable, puede utilizarse tanto como una herramienta de línea de comandos como una librería en sus proyectos de Python.
